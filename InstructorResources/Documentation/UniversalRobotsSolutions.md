# Universal Robots UR10e Solutions

The alternate UR10e learner lessons remain in `Data/UniversalRobots/Scripts/`. Their instructor solutions are grouped in `InstructorResources/Solutions/UniversalRobots/`.

Open `RoboticManipulators.prj` before running these solutions so their data and model paths resolve from the module project.

## Lesson Solutions

- [Coordinate System Transformations](../Solutions/UniversalRobots/CoordinateSystemTransformationsURSoln.m)
- [DH Parameters](../Solutions/UniversalRobots/DHParametersURSoln.m)
- [Forward Kinematics](../Solutions/UniversalRobots/ForwardKinematicsURSoln.m)
- [Inverse Kinematics](../Solutions/UniversalRobots/InverseKinematicsURSoln.m)

Select a lesson link to open its solution in the MATLAB editor from the Instructor Resources app.

## Simulation Exercise Solutions

The same solution folder contains these completed Simulink models:

- `ManipulatorTrajectoryPlanningRandomizedUREx2Soln.slx`
- `ManipulatorTrajectoryPlanningRandomizedUREx3Soln.slx`

Open these models directly from MATLAB's Project panel or Current Folder browser. The learner model stays in `Data/UniversalRobots/Models/`; the data, pictures, and geometry stay in `Data/UniversalRobots/Supplements/`.

These instructor solutions are removed along with the rest of `InstructorResources/` when you create a student version of the module.
